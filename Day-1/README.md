# Day 1 - Introduction to LLMs and API Integration

## Objective
To build a basic AI assistant for Sweet Crumbs
Home Bakery using the Groq API.

## Concepts Learned
- Large Language Models (LLMs)
- Next-token prediction
- Tokens and token usage
- Temperature
- Context window
- Hallucination
- API integration

## Features
- Answers bakery customer questions.
- Provides product prices.
- Follows bakery rules.
- Displays token usage.

## Technologies Used
- Python
- Google Colab
- Groq API
- OpenAI SDK

## How to Run
1. Install openai using pip.
2. Configure GROK_API_KEY in Colab Secrets.
3. Execute task.py in Google Colab.

## Learning Outcome
Understanding how to connect Python with an LLM
through an API and generate responses using prompts.
